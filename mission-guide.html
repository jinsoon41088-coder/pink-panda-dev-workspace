🎯 미션 소개

Linux 명령어와 Docker, Git, GitHub를 활용하여 개발 환경을 직접 구성하는 미션입니다.

1. 절대 경로와 상대 경로

절대 경로는 최상위 디렉터리부터 시작하는 전체 주소입니다.

/home/jin/pink-panda-workspace

상대 경로는 현재 위치를 기준으로 한 주소입니다.

./docs/WORKSTATION.md
절대 경로는 전체 주소이고, 상대 경로는 현재 위치를 기준으로 파일을 찾아가는 주소입니다.

2. 파일 권한 r/w/x, 755, 644

r = 읽기(4), w = 쓰기(2), x = 실행(1)

755: 소유자 rwx, 그룹 r-x, 기타 사용자 r-x

644: 소유자 rw-, 그룹 r--, 기타 사용자 r--

chmod 755 hello.sh
chmod 644 hello.txt
755는 소유자가 읽기·쓰기·실행을 할 수 있고, 644는 소유자만 쓰기 권한을 갖는 설정입니다.

3. Docker 커스텀 이미지

Dockerfile에 기본 이미지와 필요한 파일을 지정하여 나만의 이미지를 만듭니다.

FROM nginx:alpine
COPY index.html /usr/share/nginx/html/index.html
docker build -t pink-panda-web:1.0 .
Dockerfile을 작성하고 docker build 명령어로 나만의 커스텀 이미지를 만들 수 있습니다.

4. Docker 포트 매핑

컴퓨터의 8084번 포트를 컨테이너의 80번 포트와 연결하는 예시입니다.

docker run -d -p 8084:80 --name pink-panda-web pink-panda-web:1.0

접속 주소: http://localhost:8084

포트 매핑을 통해 컴퓨터의 웹브라우저에서 컨테이너 안의 웹서버에 접속할 수 있습니다.

5. Docker 볼륨(영속 데이터)

볼륨은 컨테이너가 삭제되어도 데이터를 유지할 수 있는 저장 공간입니다.

docker volume create pink-panda-data
docker volume ls
컨테이너를 삭제한 뒤에도 볼륨에 저장된 데이터를 새로운 컨테이너에서 다시 확인할 수 있습니다.

6. Git과 GitHub의 차이

Git: 내 컴퓨터에서 파일의 변경 이력을 기록하는 버전 관리 도구

GitHub: Git 저장소를 온라인에 보관하고 공유·협업하는 플랫폼

git status
git add README.md
git commit -m "Add mission explanations"
git push origin main
Git으로 변경 이력을 기록하고 GitHub에 업로드하여 다른 사람과 공유할 수 있습니다.

🎤 동료평가 마무리 발표

이번 미션에서는 Linux의 파일 경로와 권한을 배우고, Docker로 웹서버 이미지를 만들어 실행했습니다. 포트 매핑을 이용해 웹페이지에 접속하고, 볼륨을 이용해 데이터를 유지하는 방법도 실습했습니다. 마지막으로 Git과 GitHub를 사용하여 작업 내용을 기록하고 공유했습니다.
